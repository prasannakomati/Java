Arithmetic Operators in Java

Arithmetic operators are used to perform basic mathematical operations like addition, subtraction, multiplication, division, etc.

Simple
Math
in Java
Operator Name Description Example Result
+ Addition Adds two values. 5 + 3 8
− Subtraction Subtracts the right value from the left value. 10 - 4 6
* Multiplication Multiplies two values. 6 * 7 42
/ Division Divides the left value by the right value. 15 / 3 5
% Modulus (Remainder) Returns the remainder of the division. 10 % 3 1

Example in Java

public class ArithmeticExample {
    public static void main(String[] args) {
        int a = 10;
        int b = 3;

        System.out.println("Addition: " + (a + b));       // 13
        System.out.println("Subtraction: " + (a - b));    // 7
        System.out.println("Multiplication: " + (a * b)); // 30
        System.out.println("Division: " + (a / b));       // 3
        System.out.println("Modulus: " + (a % b));        // 1
    }
}

💡 Key Points

  • All arithmetic operators work with numbers (int, float, double, etc.).
  • Division with integers gives an integer result (e.g., 5 / 2 = 2).
  • To get a decimal result, use a floating-point value (e.g., 5.0 / 2 = 2.5).
  • The % operator gives the remainder.

✅ Quick Tip

You can use these operators in expressions, assignments and within conditions (like if, while, for).
