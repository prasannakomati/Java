Unary Operators in Java

Unary operators perform operations on a single operand (one variable or value), such as incrementing, decrementing, or changing its sign

📌 What are Unary Operators?

A unary operator is an operator that works on only one operand (a variable or value).

Example: a++ uses one variable, a, and increases its value by one.

⭐ Types of Unary Operators

Operator Name Description Example Result
++ Increment Increases a variable by 1. a++ 10 → 11
-- Decrement Decreases a variable by 1. a-- 10 → 9
+ Unary Plus Indicates a positive numeric value. +a 10
- Unary Minus Reverses the sign of a numeric value. -a -10
! Logical NOT Reverses a boolean value. !true false
~ Bitwise Complement Reverses all bits of an integer. ~10 -11
Java Example
public class UnaryOperators {
    public static void main(String[] args) {

        int a = 10;

        System.out.println("Post-increment: " + a++);
        System.out.println("Current value: " + a);

        System.out.println("Pre-increment: " + ++a);

        int b = 10;
        System.out.println("Post-decrement: " + b--);
        System.out.println("Pre-decrement: " + --b);

        System.out.println("Unary plus: " + +a);
        System.out.println("Unary minus: " + -a);

        boolean flag = true;
        System.out.println("Logical NOT: " + !flag);

        System.out.println("Bitwise complement: " + ~10);
    }
}

💡 Key Points
  • ✓ a++ returns the old value in the expression, then increments a.
  • ✓ ++a increments a first, then returns the updated value.
  • ✓ a-- and --a follow the same rules but decrease by one.
  • ✓ ! works with boolean values.
  • ✓ ~ flips every bit of an integer.
✔ Quick Tip
Post means use the current value first. Pre means update the value first.
