Logical Operators in Java

Logical operators combine or reverse boolean conditions and return a boolean result (true or false).

Operator Name Description Example Result
&& Logical AND Returns true only if both conditions are true. (true && true) true
|| Logical OR Returns true if at least one condition is true. (true || false) true
! Logical NOT Reverses the result: true becomes false and false becomes true. !true false
Example in Java </>
package com.example.practice;

public class LogicalOperators {
  public static void main(String[] args) {

    int a = 10;
    int b = 5;
    int c = 20;

    System.out.println("AND : " + (a > b && c > a)); // true
    System.out.println("AND : " + (a > b && a > c)); // false
    System.out.println("OR  : " + (a > c || b < c)); // true
    System.out.println("OR  : " + (a < b || c < b)); // false
    System.out.println("NOT : " + !(a > b));        // false
    System.out.println("NOT : " + !(a < b));        // true
  }
}

Key Points
  • ✓Logical operators work on boolean values and return true or false.
  • ✓&& and || use short-circuiting: the right side is skipped when the left side already decides the result.
  • ✓Combine several relational checks, like age >= 18 && hasId.
  • ✓Use parentheses to make the order clear. ! runs first, then &&, then ||.
✔ Quick Tip
Use && when all conditions must pass, || when any one is enough, and ! to flip a condition.
