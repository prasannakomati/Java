Relational Operators in Java

Relational operators are used to compare two values and return a boolean result (true or false).

Operator Name Description Example Result
== Equal to Checks if the left value is equal to the right value. 5 == 5 true
!= Not equal to Checks if the left value is not equal to the right value. 5 != 3 true
> Greater than Checks if the left value is greater than the right value. 10 > 5 true
< Less than Checks if the left value is less than the right value. 3 < 7 true
>= Greater than or equal to Checks if the left value is greater than or equal to the right value. 5 >= 5 true
<= Less than or equal to Checks if the left value is less than or equal to the right value. 4 <= 7 true
Example in Java </>
package com.example.practice;

public class RelationalOperators {
  public static void main(String[] args) {

    int a = 10;
    int b = 5;

    System.out.println("a == b : " + (a == b));  // false
    System.out.println("a != b : " + (a != b));  // true
    System.out.println("a > b : " + (a > b));  // true
    System.out.println("a < b : " + (a < b));  // false
    System.out.println("a >= b : " + (a >= b));  // true
    System.out.println("a <= b : " + (a <= b));  // false
  }
}
Execution Console Output:
a == b : false
a != b : true
a > b : true
a < b : false
a >= b : true
a <= b : false
💡
Key Points
  • ✓ Relational operators return a boolean value (true or false).
  • ✓ They are used in conditions (if, else, while, for).
  • ✓ The result of a comparison is always boolean, not a number.
  • ✓ You can compare numbers, characters and strings (using equals() for strings).
✔ Quick Tip
Use relational operators inside if conditions to control the flow of your program.
