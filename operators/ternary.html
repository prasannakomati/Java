Ternary Operator in Java

The ternary operator is a short way to write a simple if-else condition using ? and :.

Operator Name Description Example Result
?: Ternary / Conditional The ternary operator checks a condition and returns one of two values based on whether the condition is true or false. (10 > 20) ? 10 : 20 20
⌘
Syntax
result = (condition) ? valueIfTrue : valueIfFalse;
  • ✓condition — the condition Java checks.
  • ✓? — choose the first value when the condition is true.
  • ✓: — choose the second value when the condition is false.
Example in Java </>
package com.operators.practice;

public class TernaryOperator
{
    public static void main(String[] args)
    {
        // Ternary Operator
        int a = 10;
        int b = 20;

        int result = (a > b) ? a : b;

        System.out.println("Biggest Number: " + result);
    }
}
Execution Console Output: Biggest Number: 20
💡
How It Works
  • 1a = 10 and b = 20.
  • 2a > b checks whether 10 is greater than 20.
  • 3The condition is false, so Java selects b.
  • 4The result is 20.
📘
Key Points
  • ✓The ternary operator uses three parts: condition, true expression, and false expression.
  • ✓It returns one of the two expressions based on the condition.
  • ✓Use it for simple choices; use if-else when logic is more complex.
✔ Quick Tip
If the condition is true, Java chooses the value after ?. If false, Java chooses the value after :.
